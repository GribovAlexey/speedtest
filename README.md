# speedtest

Скрипт последовательно качает один и тот же файл N раз
и выводит среднюю скорость скачивания в МБ/с.

## Что делает

- делает N последовательных запросов к указанному URL;
- замеряет время и объём каждого;
- считает среднюю скорость (суммарный объём / суммарное время);
- печатает строку по каждой попытке и итоговую сводку.

Ошибки на отдельных запросах не роняют серию — они учитываются,
остальные запросы продолжаются.

## Требования

- Python 3.9+
- requests
- python-dotenv

## Установка

```bash
python -m venv .venv
source .venv/bin/activate          # для Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

```bash
cp .env.example .env
```

| Переменная           | По умолчанию               | Смысл                          |
|----------------------|----------------------------|--------------------------------|
| `SPEEDTEST_URL`      | ссылка на speed cloudflare | URL для скачивания      |
| `SPEEDTEST_REQUESTS` | `10`                       | Сколько последовательных запросов |
| `SPEEDTEST_TIMEOUT`  | `30`                       | Таймаут одного запроса, сек    |

## Запуск

```bash
# из .env
python speedtest.py

# явный URL
python speedtest.py https://example_url.com/big.jpg

# переопределить число запросов и таймаут
python speedtest.py https://example_url.com/big.jpg -n 5 -t 60
```

## Нюансы

- **Считаем скорость в МБ/с.**
- **Один `requests.Session` на серию** — соединение переиспользуется,
  первый запрос может быть чуть медленнее из-за TLS-хендшейка.
- **`Cache-Control: no-cache`** — для избегания кеширования.
- **Последовательные запросы**.
- **Не картинка, а speed cloudflare** - чтобы не попасть на лимитер ресурса.
